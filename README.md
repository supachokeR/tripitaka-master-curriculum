# พระไตรปิฎก Journey

หลักสูตรภาษาไทย 120 บทสำหรับอ่านพระไตรปิฎกบาลีอย่างมีบริบท แยกตัวบทออกจากคำอธิบาย ตรวจสอบแหล่งอ้างอิงได้ และนำไปพิจารณาในชีวิตอย่างไม่เพิ่มทุกข์

## อ่านบนเว็บ

หลังเชื่อมโครงการนี้กับ GitHub Pages เว็บไซต์จะเผยแพร่จากสาขา `gh-pages` โดยเวิร์กโฟลว์ใน `.github/workflows/publish.yml` จะสร้างเว็บใหม่ทุกครั้งที่มีการส่งงานขึ้นสาขา `main`.

เว็บไซต์เผยแพร่ที่ [supachoker.github.io/tripitaka-master-curriculum](https://supachoker.github.io/tripitaka-master-curriculum/) และระบบจะสร้างฉบับใหม่เมื่อมีการส่งงานขึ้นสาขา `main`.

## โครงสร้าง

- `content/` — บทเรียน Markdown และหน้าเริ่มต้นของเว็บไซต์
- `tripitaka_master_curriculum_codex.md` — หลักสูตรฉบับรวม
- `mkdocs.yml` — การตั้งค่าเว็บอ่าน
- `CHANGELOG.md` — บันทึกการเปลี่ยนแปลงที่เผยแพร่
- `CONTRIBUTING.md` — วิธีแจ้งคำผิด ลิงก์เสีย และข้ออ้างอิง

## ตรวจตัวบทและแหล่งอ้างอิง

ทุกบทมีหัวข้อ **Original Text Trail** สำหรับตามรอยตัวบทหรือแหล่งข้อมูลที่เกี่ยวข้อง ควรตรวจบริบทและฉบับแปลจากแหล่งต้นทางก่อนอ้างอิงต่อ

## สัญญาอนุญาต

เฉพาะเนื้อหาที่ผู้จัดทำสร้างขึ้นในโครงการนี้ เผยแพร่ภายใต้ [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). ตัวบท คำแปล เครื่องหมายการค้า และสื่อจากแหล่งภายนอกยังอยู่ภายใต้เงื่อนไขของเจ้าของสิทธิ์เดิมและไม่ได้ถูกอนุญาตใหม่โดยไฟล์นี้

ก่อนเปิดตัวสู่สาธารณะ ให้ผู้ถือสิทธิ์ของโครงการตรวจยืนยันชื่อที่ใช้ให้เครดิตและนโยบายการนำไปใช้เชิงพาณิชย์อีกครั้ง
