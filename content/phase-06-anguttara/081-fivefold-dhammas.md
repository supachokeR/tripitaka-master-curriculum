# บทที่ 81 — ธรรมหมวด 5

> **คำถามนำทาง:** กำลังภายในที่พาให้ฝึกต่อได้ควรมีอะไรบ้าง และเราจะทำให้ศรัทธา วิริยะ สติ สมาธิ และปัญญาเกื้อหนุนกันโดยไม่สุดโต่งด้านใดด้านหนึ่งได้อย่างไร?

## 1. Enter the Scene

🎭 ภพติดตามคำสอนหลายช่องจนรู้สึกว่าตนต้อง “ศรัทธาให้มากขึ้น” เขาจึงหยุดตั้งคำถาม แต่ไม่นานก็เชื่อคำชวนลงทุนที่อ้างธรรมะแล้วเสียเงิน ขณะเดียวกันเพื่อนของเขาเชื่อเฉพาะสิ่งที่พิสูจน์ได้ทันที จนไม่ยอมลองฝึกอะไรต่อเนื่องเลย

ทั้งสองกรณีทำให้เห็นว่ากำลังทางธรรมไม่ได้มีด้านเดียว ศรัทธาที่ไม่มีปัญญาอาจเปราะบาง ปัญญาที่ไม่ยอมทดลองอาจกลายเป็นการยืนอยู่นอกทาง วิริยะที่ขาดสติอาจกลายเป็นการฝืน และสมาธิที่ขาดการตรวจผลก็อาจกลายเป็นการหลบปัญหา

ธรรมหมวด 5 ในบทนี้จึงใช้ **พละห้า** เป็นภาพของกำลังที่ทำงานร่วมกัน ไม่ใช่รายการคะแนนส่วนตัว

## 2. Big Question

> พละห้าคือคุณลักษณะที่ต้องมีมากที่สุดทุกข้อ หรือเป็นกำลังที่ต้องสัมพันธ์และตรวจทิศทางของกันและกัน?

พระสูตรกล่าวถึงพละห้าเป็นชุด: ศรัทธา วิริยะ สติ สมาธิ และปัญญา และเชื่อมแต่ละกำลังเข้ากับชุดการปฏิบัติอื่น จึงควรอ่านเป็นเครือข่าย ไม่ใช่การเลือกฝึกเพียงข้อที่เราชอบ

## 3. Canonical Context

📜 **AN 5.14** ระบุพละห้าคือ ศรัทธา วิริยะ สติ สมาธิ และปัญญา พร้อมขยายความของแต่ละข้อ: ศรัทธาในพระพุทธเจ้าผู้ตรัสรู้ วิริยะเพื่อการละอกุศลและเจริญกุศล สติที่ระลึกสิ่งที่ทำและกล่าวได้ สมาธิในความหมายของฌานสี่ และปัญญาที่เห็นความเกิด–ดับอันนำไปสู่ความสิ้นทุกข์

📜 **AN 5.15** ชี้ให้เห็นพละแต่ละข้อผ่านธรรมหมวดอื่น: พลังศรัทธาเห็นได้ในองค์โสตาปัตติ พลังวิริยะในความเพียรชอบสี่ พลังสติในสติปัฏฐานสี่ พลังสมาธิในฌานสี่ และพลังปัญญาในอริยสัจสี่

📜 **SN 50.6** เปรียบผู้เจริญพละห้ากับแม่น้ำคงคาที่ลาดเอียงไปทางทิศตะวันออก คือมีทิศโน้มไปสู่ความดับทุกข์ ถ้อยคำนี้พูดถึงการพัฒนาชุดธรรมในบริบทของทางพ้นทุกข์ ไม่ใช่สัญญาว่าทุกคนจะสำเร็จเร็วเท่ากัน

## 4. Core Teaching

### 4.1 พละห้า

📜 พละห้าตาม AN 5.14–15

| พละ | แก่นในพระสูตร | ความเข้าใจเบื้องต้น |
|---|---|---|
| ศรัทธา | ความเชื่อมั่นในพระพุทธเจ้าผู้ตรัสรู้ | เปิดใจให้เรียนและทดลอง โดยไม่ละทิ้งการตรวจสอบ |
| วิริยะ | การละอกุศลและเจริญกุศล | ลงมืออย่างต่อเนื่องและพอดีกำลัง |
| สติ | ระลึกสิ่งที่ได้ทำและกล่าว | รู้ตัวต่อประสบการณ์และไม่ลืมเจตนาที่ฝึก |
| สมาธิ | ฌานสี่ | ความตั้งมั่นลึกตามนิยามคัมภีร์ ไม่ใช่เพียงผ่อนคลายชั่วคราว |
| ปัญญา | เห็นความเกิดและดับ นำสู่ความสิ้นทุกข์ | เห็นเหตุปัจจัยและไม่ยึดความคิดของตนง่าย ๆ |

🔎 คำว่า “สมาธิ” ใน AN 5.14 มีความหมายเฉพาะถึงฌานสี่ การนั่งเงียบแล้วใจนิ่งขึ้นในชีวิตประจำวันอาจเป็นประโยชน์ แต่ไม่ควรอ้างว่าเท่ากับฌานหรือผลทางธรรมที่พระสูตรกล่าว

### 4.2 พละแต่ละข้อโยงกับทาง

📜 AN 5.15 ทำให้เห็นว่าแต่ละพละมีพื้นที่ฝึก

```text
ศรัทธา → องค์โสตาปัตติ
วิริยะ → ความเพียรชอบสี่
สติ    → สติปัฏฐานสี่
สมาธิ  → ฌานสี่
ปัญญา → อริยสัจสี่
```

🔎 แผนที่นี้ช่วยกันความเข้าใจผิดว่า “มีศรัทธาอย่างเดียวก็พอ” หรือ “มีปัญญาอย่างเดียวก็พอ” ศรัทธาเปิดให้เดิน วิริยะทำให้ทำจริง สติไม่ให้หลงทิศ สมาธิทำให้ใจตั้งมั่น และปัญญาตรวจเห็นเหตุและผล

## 5. Deep Explanation

คำว่า “พละ” แปลว่ากำลัง แต่ไม่จำเป็นต้องนึกถึงความแข็งหรือการกดทับ อาจเป็นกำลังที่ทำให้ไม่ถูกสิ่งตรงข้ามดึงไปง่าย เช่น ศรัทธาที่มีปัญญาช่วยไม่ให้ความสงสัยทำให้หยุดเรียนทุกอย่าง วิริยะที่มีสติช่วยไม่ให้ความอยากสำเร็จทำให้ฝืนเกินกำลัง และสมาธิที่มีปัญญาช่วยไม่ให้ยึดความสงบเป็นที่หลบปัญหา

การพูดว่าสมดุลไม่ได้หมายถึงแบ่งเวลาหรือคะแนนให้เท่ากันทุกวัน บางช่วงอาจต้องใช้สติมากขึ้นเพราะใจฟุ้ง บางช่วงต้องใช้ปัญญาตรวจคำกล่าวอ้าง บางช่วงต้องพักและให้คนอื่นช่วยก่อนที่วิริยะจะกลับมาได้

พละห้าจึงไม่ใช่แบบทดสอบระดับบุญหรือระดับจิต เป็นภาษาชวนสังเกตว่า ตอนนี้กำลังใดอ่อน กำลังใดนำแรงเกินไป และควรเกื้อหนุนอย่างไร

## 6. Example / Everyday Life

🎭 ภพเห็นโฆษณาคอร์สที่อ้างว่า “นั่งสามวันเปิดปัญญา ถ้าไม่เชื่อแปลว่าศรัทธาน้อย” เขาใช้พละห้าเป็นคำถาม

| พละ | คำถามของภพ |
|---|---|
| ศรัทธา | คำสอนนี้ชวนให้ทดลองอย่างมีเหตุผล หรือบังคับให้เชื่อผู้สอน? |
| วิริยะ | โปรแกรมพอดีกับสุขภาพ เวลา และภาระของฉันหรือกำลังชวนฝืน? |
| สติ | ขณะอ่าน ฉันกำลังถูกความกลัวพลาดโอกาสครอบงำหรือไม่? |
| สมาธิ | สิ่งที่เสนอมีขอบเขตชัดหรือเอาคำว่าสมาธิมารับประกันผลเกินจริง? |
| ปัญญา | มีแหล่งอ้างอิง หลักฐาน ค่าใช้จ่าย และความเสี่ยงที่ตรวจสอบได้หรือไม่? |

💡 ภพอาจเลือกไม่สมัคร ไม่ใช่เพราะศรัทธาน้อย แต่เพราะใช้ศรัทธาและปัญญาเดินด้วยกัน จากนั้นเขาเลือกทำการฝึกสั้นที่ปลอดภัย อ่านพระสูตร และหาเพื่อนร่วมเรียนที่เปิดให้ถาม

## 7. Dharma Map

```text
เปิดใจเรียนรู้ด้วยศรัทธาที่มีเหตุผล
          ↓
ลงมืออย่างพอดีด้วยวิริยะ
          ↓
รู้สภาพและเจตนาด้วยสติ
          ↓
ทำใจให้ตั้งมั่นตามฐานที่เหมาะ
          ↓
ตรวจเหตุ ผล และการยึดด้วยปัญญา
          ↓
ปรับการฝึกให้เกื้อหนุนกันอีกครั้ง
```

🔎 แผนที่นี้เป็นวงจร ไม่ใช่ขั้นบันไดที่ทำเสร็จแล้วผ่านถาวร

## 8. Canonical / Explanation / Application

| ระดับ | สิ่งที่ควรแยกให้ชัด |
|---|---|
| 📜 Canonical | AN 5.14 ให้รายชื่อและคำอธิบายพละห้า; AN 5.15 เชื่อมพละแต่ละข้อกับชุดการปฏิบัติ; SN 50.6 เปรียบทิศของผู้เจริญพละห้ากับคงคาไหลสู่ตะวันออก |
| 🔎 Explanation | พละห้าควรเกื้อหนุนและถ่วงดุลกัน ศรัทธาไม่ใช่เชื่อตาม สมาธิในพระสูตรมีความหมายลึกกว่าการพักผ่อน และปัญญาไม่ใช่ความรู้เพื่อชนะคน |
| 💡 Application | ใช้พละห้าเป็นคำถามตรวจวิธีฝึก ข่าว หรือครูผู้สอน แล้วปรับขนาดของการฝึกให้ปลอดภัยและพอดีกำลัง |

ข้อควรระวัง: อย่าใช้พละห้าเพื่อเปรียบเทียบว่าผู้ใด “อ่อน” หรือ “สูงกว่า” และอย่าฝืนฝึกสมาธิเมื่อมีอาการตื่นตระหนก ท่วมท้น หรือปัญหาสุขภาพที่ต้องดูแล หากการฝึกทำให้อาการแย่ลง ให้หยุด เปลี่ยนฐาน และปรึกษาผู้เชี่ยวชาญหรือผู้สอนที่รับผิดชอบตามความจำเป็น

## 9. Remember

> **ศรัทธาเปิดทาง — วิริยะลงมือ — สติไม่หลง — สมาธิตั้งมั่น — ปัญญาตรวจผล**

นี่เป็นคำจำของหลักสูตรเพื่อช่วยระลึกพละห้า ไม่ใช่ถ้อยคำจากพระสูตร

## 10. Reflect

1. ฉันมีแนวโน้มพึ่งกำลังข้อใดมาก และข้อใดที่มักละเลย?
2. ศรัทธาของฉันเปิดให้เรียนรู้หรือกำลังปิดคำถามสำคัญ?
3. วิริยะของฉันพอดีกับร่างกายและชีวิตตอนนี้หรือกลายเป็นการฝืน?
4. ในเรื่องหนึ่งที่กำลังตัดสินใจ ปัญญาต้องตรวจเหตุ ผล และข้อมูลอะไรเพิ่ม?

## 11. Practice

ตลอด 5 วัน เลือกเหตุการณ์หนึ่งในแต่ละวัน แล้วจดพละห้าแบบสั้น

1. **ศรัทธา:** ฉันกำลังไว้วางใจอะไร เพราะเหตุใด  
2. **วิริยะ:** ก้าวเล็กที่ทำได้จริงคืออะไร  
3. **สติ:** ตอนนี้กาย ใจ และเจตนาเป็นอย่างไร  
4. **สมาธิ:** ฐานใดช่วยให้ใจพออยู่กับเรื่องนี้โดยไม่จม เช่น เดินช้า ๆ หรือสัมผัสเท้าที่พื้น  
5. **ปัญญา:** ข้อมูล เหตุปัจจัย หรือผลกระทบใดที่ยังต้องตรวจ  

คำว่า “สมาธิ” ในแบบฝึกนี้เป็นภาษาประยุกต์สำหรับความตั้งมั่นเบื้องต้น ไม่ใช่การอ้างว่าได้ฌาน
