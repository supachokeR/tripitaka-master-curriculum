# พระไตรปิฎก Journey

> หลักสูตร 120 บทสำหรับอ่านพระไตรปิฎกบาลีอย่างมีบริบท ตรวจสอบที่มาได้ และนำไปพิจารณาในชีวิตอย่างไม่เพิ่มทุกข์

## เริ่มที่นี่

ถ้าเพิ่งเริ่มอ่าน ให้เปิด [บทที่ 1 — พระไตรปิฎกคืออะไร?](phase-01-foundation/001-what-is-tipitaka.md) แล้วเรียนตามลำดับได้เลย แต่ละบทมีฉากร่วมสมัย บริบทคัมภีร์ คำอธิบาย แบบฝึก และลิงก์ตามรอยตัวบทต้นทาง

## แผนที่หลักสูตร

| ช่วงการเรียน | เนื้อหา | บท |
|---|---|---:|
| Phase 1 | พื้นฐานและวิธีอ่าน | 1–10 |
| Phase 2 | พระวินัย | 11–30 |
| Phase 3 | ทีฆนิกาย | 31–42 |
| Phase 4 | มัชฌิมนิกาย | 43–60 |
| Phase 5 | สังยุตตนิกาย | 61–76 |
| Phase 6 | อังคุตตรนิกาย | 77–90 |
| Phase 7 | ขุททกนิกาย | 91–105 |
| Phase 8 | พระอภิธรรมปิฎก | 106–117 |
| Phase 9 | บูรณาการและเรียนต่อ | 118–120 |

## วิธีใช้หลักสูตร

1. อ่านบทหนึ่งให้จบโดยไม่ต้องรีบทำความเข้าใจทุกศัพท์
2. แยกสิ่งที่ตัวบทกล่าวออกจากคำอธิบายและการประยุกต์
3. เปิดลิงก์ในหัวข้อ **Original Text Trail** เพื่อดูแหล่งอ้างอิง
4. เลือกแบบฝึกเล็กที่ปลอดภัยและเหมาะกับสถานการณ์ของตน
5. หากพบข้อความที่หนักเกินกำลังหรือเกี่ยวข้องกับอันตราย ให้พักและขอความช่วยเหลือที่เหมาะสมก่อน

## ขอบเขตและความปลอดภัย

หลักสูตรนี้จัดทำเพื่อการศึกษา ไม่ใช่คำวินิจฉัยทางการแพทย์ กฎหมาย หรือสุขภาพจิต และไม่ควรใช้แทนความช่วยเหลือฉุกเฉิน การอ้างอิงตัวบทและคำแปลให้ตรวจตามแหล่งต้นทางในแต่ละบทเสมอ

## ช่วยพัฒนาหลักสูตร

หากพบคำผิด ลิงก์เสีย หรือข้ออ้างอิงที่ควรตรวจสอบ โปรดแจ้งผ่านช่องทางรายงานของโครงการ โดยระบุเลขบท ตำแหน่ง และแหล่งอ้างอิงที่เกี่ยวข้อง เพื่อให้แก้ไขอย่างโปร่งใสในบันทึกการเปลี่ยนแปลง
